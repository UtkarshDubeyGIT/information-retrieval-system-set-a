1. Executive Summary

This project delivers a complete software implementation solving two fundamental Information Retrieval (IR) problems:

  • Q1. Automatic Document Categorization: Converts unstructured documents into high-dimensional TF-IDF vector space, groups documents using K-Means and Hierarchical Agglomerative clustering, automatically extracts semantic cluster labels, and resolves user queries by scoring cosine similarity against cluster centroids and documents.
  • Q2. Multimedia Search and Retrieval: Maintains a searchable database of text documents and images with metadata, supports weighted multi-field keyword search, implements content-based image retrieval (CBIR) using 48-dimensional RGB color histograms, and enables multimodal query score fusion.

2. Question 1 — Automatic Document Categorization System

2.1 Mathematical & Algorithmic Formulation

  • TF-IDF Vector Space Model: Computes sublinear term frequency TF = 1 + log(tf) and smoothed inverse document frequency IDF = log((1 + |D|)/(1 + df)) + 1. Every document vector is L2-normalized onto the unit hypersphere.
  • Clustering Methods: Supports K-Means Clustering (minimizing within-cluster inertia) and Hierarchical Agglomerative Clustering (with Ward's minimum variance criterion).
  • Automatic Thematic Labeling: Identifies top terms with maximum centroid weights to synthesize descriptive cluster names (e.g. Cluster 4: neural, memory, billions, learning).
  • User Query Relevance: Vectorizes query text, computes cosine similarity against cluster centroids to identify the most relevant cluster, and calculates cosine similarity against all document vectors to rank relevant documents with scores in [0.0, 1.0].

3. Question 2 — Multimedia Search and Retrieval System

3.1 Metadata Architecture & Keyword Search

Structured records maintain title, description, category, upload_date, media_type, file_path, and tags. Keyword searching applies hierarchical field weights (Title: 3.0x, Tags: 2.5x, Category: 2.0x, Description: 1.0x) blended with TF-IDF cosine similarity.

3.2 Content-Based Image Retrieval (CBIR) via Color Histograms

  • Feature Vector: 16 bins per channel across Red, Green, and Blue (48 dimensions total), L1-normalized so sum is 1.0.
  • Histogram Intersection Metric: Computes K(H_q, H_t) = sum(min(H_q, H_t)) in [0.0, 1.0].
  • Color Discrimination: Querying a green leaf specimen accurately retrieves the forest image (0.3172 similarity) while scoring 0.0000 against red and blue images.
